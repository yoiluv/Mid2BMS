# Mid2BMS v20260923

## 配布形式

- Windows x64自己完結版
- ZIPを展開し、`Mid2BMS.exe`を実行
- .NET Desktop Runtimeの別途インストールは不要

## 主な変更

- .NET 10 / SDK-style projectへ移行
- Core処理をWinFormsから分離
- 回帰テストとGolden Masterを整備
- KeySoundManifestと命名Strategyを導入
- `Legacy`、`Sequential`、`Track + Sequential`命名に対応
- `TrackMode` / `TrackSettings`を導入
- Blue / Purple / Red混在変換に対応
- Redを含む混在時のSequenceLayerとXChainに対応
- 変換入力と結果をRequest / Resultモデルへ統合
- トラック設定画面から各トラックのMode、Drums、OneShot、Chord、Ignore、XChainを編集可能
- Mid2MML画面からFile Namingを選択可能
- File Namingの選択を`ctrl.json`へ保存
- アプリケーションのタイトルバーへ製品バージョンを表示

既存のBlue、Purple、Red、Chord、Drums、OneShot、SequenceLayerについては、7 fixture・91ファイルのGolden Masterで従来出力との一致を確認している。追加の回帰シナリオで連番命名、Blue / Purple / Red混在、SequenceLayer、XChainおよびWinForms UI契約も確認している。

## UIでの利用方法

Mid2MMLタブの`File Naming`から命名方式を選択する。MIDI変換後のトラック確認画面で「変更する」を選ぶと、各トラックのModeをBlue / Purple / Redから選択できる。

PurpleではChordを使用できない。XChainはSequenceLayerを有効にしたRedトラックでのみ使用できる。

## 現時点の制限

- `Kick [B]`のようなTrack Name metadataからModeを自動判定する機能は未実装。Modeはトラック設定画面で手動指定する。
- トラックごとの設定は変換時に適用される。MIDIファイル別の設定ファイルとしては保存しない。
- `Custom`命名Strategyは未実装。
