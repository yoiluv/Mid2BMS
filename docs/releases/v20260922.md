# Mid2BMS v20260922

## 配布形式

- Windows x64自己完結版
- ZIPを展開し、`Mid2BMS.exe`を実行
- .NET Desktop Runtimeの別途インストールは不要

## 主な変更

- .NET 10 / SDK-style projectへ移行
- Core処理をWinFormsから分離
- 回帰テストとGolden Masterを整備
- キー音manifestと命名Strategyを導入
- 全体連番・トラック別連番の命名処理をCoreへ追加
- `TrackMode` / `TrackSettings`を導入
- Core APIでBlue/Purpleトラック混在変換に対応

既存のBlue、Purple、Red、Chord、Drums、OneShot、SequenceLayerについては、7 fixture・91ファイルのGolden Masterで従来出力との一致を確認している。

## 現時点の制限

- WinForms画面は従来どおりプロジェクト全体のBlue/Purple/Redを選択する。トラック別Mode指定UIは未実装。
- Blue/Purple混在はCore APIから利用できるが、通常画面からはまだ選択できない。
- RedとBlue/Purpleの混在、および混在時のSequenceLayerは未対応。
- 新しい連番命名Strategyを選択する画面と設定保存は未実装。
